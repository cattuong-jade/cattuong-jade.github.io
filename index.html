Dang Bai Cat Tuong

Internal publishing tool of Phỉ Thuý Cát Tường (Cẩm Thạch Cát Tường)

What it is

Dang Bai Cat Tuong is a small command-line tool used only by the owner of the YouTube channel "Cẩm Thạch Cát Tường (Phỉ Thuý Cát Tường)". It runs on the owner's own computer and uploads the channel's own finished videos to that same channel, with title, description, thumbnail and a scheduled publish time.

How it uses the YouTube API

  • videos.insert: upload a video to the owner's channel as private with a scheduled publishAt time.
  • thumbnails.set: set the custom thumbnail of that uploaded video.
  • channels.list (mine=true): show the connected channel name so the owner can confirm the right channel.

It does not read, store or display data of any other YouTube user or channel. It is not offered to the public.
