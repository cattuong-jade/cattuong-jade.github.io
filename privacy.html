Privacy Policy

Dang Bai Cat Tuong · Last updated: 11 November 2026

Dang Bai Cat Tuong ("the tool") is an internal tool of Phỉ Thuý Cát Tường. It is used only by the owner of the YouTube channel "Cẩm Thạch Cát Tường (Phỉ Thuý Cát Tường)" to upload that channel's own videos. It uses YouTube API Services.

YouTube Terms and Google Privacy Policy

By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

  • Permission to upload videos and set thumbnails on the signed-in channel (youtube.upload).
  • The signed-in channel's name and ID (youtube.readonly, channels.list mine=true), only to confirm the correct channel is connected.

The tool does not access, collect or display data of any other user or channel.

How data is used, stored and shared

  • The OAuth refresh token is stored only in a local configuration file on the owner's computer. It is never sent anywhere except to Google's OAuth server.
  • Video files, titles, descriptions and thumbnails come from the owner's computer and are sent only to YouTube.
  • No data is sold, shared with, or transferred to any third party. No analytics, advertising or tracking is used.
  • The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

TikTok

The tool may also connect to the TikTok account of Phỉ Thuý Cát Tường through TikTok's official Login Kit, using only user.info.basic and video.list, to read that account's own public videos and view counts for an internal posting calendar. This data is stored only on the owner's computer and is not shared. Access can be revoked in the TikTok app under Settings and privacy → Security → Apps and services permissions.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Removing the token line from the local configuration file deletes all stored data of the tool.
